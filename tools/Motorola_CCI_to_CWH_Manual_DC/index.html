Guidelines: How to Use Delivery Challan Generator

  1. Challan Numbering: Enter your Station Code (e.g., 065) and Sequence (e.g., 01). The Challan ID auto-generates as RLC[Code][DDMMYY][Seq].
  2. Sending Plant: Modify Sender Name, Address, GSTIN, and Transporter details as required. Receiving plant details remain fixed.
  3. Adding Items Manually: Click + Add Item Row. Enter the Service Order, Item Code, Description, HSN, Unit Price, and Quantity. Calculations update automatically.
  4. Bulk Upload:
    • Click Download Excel Template to get the standard format.
    • Fill columns: Service Order, Item Code, Description, HSN, Unit Price, Qty.
    • Click Bulk Upload (.xlsx / .csv) to import.
  5. Clear All: Click Clear All to clear editable data and reset items.
  6. Export to PDF: Click Print to PDF to generate the aligned print document.
