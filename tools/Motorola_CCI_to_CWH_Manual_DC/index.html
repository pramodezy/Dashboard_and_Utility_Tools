Guidelines: How to Use Delivery Challan Generator

  1. Challan Numbering: Enter your Station Code (e.g., 065) and Sequence (e.g., 01). The Challan ID auto-generates as RLC[Code][DDMMYY][Seq].
  2. Sending Plant: Modify Sender Name, Address, GSTIN, and Transporter details as required. Receiving plant details remain fixed.
  3. Adding Items Manually: Click + Add Item Row to insert spare parts. Enter Unit Price and Quantity; line totals, overall quantity, grand total, and amount in words calculate automatically.
  4. Bulk Upload:
    • Click Download Excel Template to get the standard format.
    • Fill columns: Item Code, Description, HSN, Unit Price, Qty.
    • Click Bulk Upload (.xlsx / .csv) to import and auto-populate all line items.
  5. Clear All: Click Clear All to wipe all items, transport inputs, and sending plant fields to start a fresh Challan.
  6. Export to PDF: Click Print to PDF. All input outlines, action buttons, and tools will be hidden to generate a clean A4 print document.
